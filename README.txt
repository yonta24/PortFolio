ACTIVER LE FORMULAIRE (2 minutes)
1. Allez sur https://web3forms.com, saisissez votre adresse e-mail : la clé d'accès arrive par mail.
2. Ouvrez index.html, cherchez COLLEZ_VOTRE_CLE_ICI et remplacez-le par votre clé (garder les guillemets).
3. Hébergez sur Vercel (glisser-déposer le dossier atlaslab_site, ou via GitHub).
4. Envoyez-vous un message test depuis la page Contact.

La clé Web3Forms est publique par conception : elle ne permet que d'envoyer des messages vers VOTRE adresse.
